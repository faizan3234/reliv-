# Images used by the Reliv scroll journey

All web-ready files are in `assets/images/` and are referenced from `js/content.js`.

| Key in `js/content.js` | WebP file | Used for |
|---|---|---|
| campus | `campus.webp` | Illustrated campus first stop |
| kiosk_done | `kiosk_done.webp` | All measurements done |
| kiosk_code | `kiosk_code.webp` | Enter code kiosk scene |
| person_report | `person_report.webp` | Person reading report |
| person_phone | `person_phone.webp` | Person using app |
| data | `data.webp` | Moving captured-data badge |
| payment_code | `payment_code.webp` | Moving payment / access code |
| report | `report.webp` | Moving health report card |
| phone | `phone.webp` | Moving phone |
| kits | `kits.webp` | Moving health kit |
| receipt | `receipt.webp` | Moving receipt, and kits receipt stop |
| payment_scene | `payment_scene.webp` | Kits payment illustrated scene |

Original high-resolution PNG samples provided in the conversation have also been included in `assets/original-png/` for manual re-editing. Some web-ready WebPs were separately cropped or composed for the previous animation and may not be identical to their PNG example. **The website uses the WebP files by default.**
