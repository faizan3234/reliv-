RUN
Extract the ZIP. Open a terminal in the folder containing index.html.
Run: python -m http.server 8000
On Windows you can use: py -m http.server 8000
Open: http://localhost:8000
Alternatively use VS Code Live Server.
No npm install, build step or API keys are required.

HOST
Upload the contents of this folder to a static website host.
Preserve relative file paths. HTTPS or localhost is needed for supported microphone use.

IMPORTANT BEHAVIOUR
All measurements, payments and dispensing in the demo are simulated.
The INR 49 first-aid kit is illustrative, not a confirmed live price.
Report and receipt downloads are printable HTML; use Print / Save as PDF.
Browser read-aloud uses recognised female voices in the chosen language.
If no suitable voice is installed/exposed, text remains visible with no male fallback.
The website does not install Microsoft/Azure voices.
Microphone availability depends on browser support and permission; the browser
may use an online speech service. Name details stay in page memory.
The full 18-value report explorer is English; the kiosk journey supports three languages.
